# Stylophone
First time doing something of my own in KICAD, will make custom PBC and research human help.

A DIY, Stylophone electronic instrument built with an ESP32 WROOM #@. It uses physical keys to generate musical notes and an I2S audio amplifier to play sound through a speaker.
